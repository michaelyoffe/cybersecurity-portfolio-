# Technical Labs

This directory contains hands-on laboratory exercises focused on technical security controls, system administration, and network hardening.

## Labs Included

| Lab Name | Primary Tools | Objective |
| :--- | :--- | :--- |
| [Active Directory Lab](./active-directory-lab.md) | Windows Server 2022, Win 11, VirtualBox | Deploy a functional domain environment with centralized user management. |
| [SQL Query Filtering](./sql-filter-queries.md) | SQL, MariaDB | Investigate security threats by filtering login logs and employee data. |
| [Linux File Permissions](./linux-lab.md) | Bash, Linux CLI | Harden system security by auditing and modifying user access levels. |
## Skills Demonstrated
* **Identity & Access Management (IAM):** Configuring Active Directory OUs, Users, and Group Policies.
* **Network Security:** Managing Static IP addressing and DNS resolution for domain stability.
* **System Hardening:** Auditing Linux permissions and SQL database logs for anomalies.
